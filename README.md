Just some of the stuff I use for my thesis. Includes:
- Metropolis-Hastings (metropolis_hastings): Needs sampler function, sample density function, prior distribution function and likelihood distribution function.
- Nelder-Mead (nelder_mead).
- Pareto distribution, quantile (qpareto), density (dpareto), distribution (ppareto) and simulation (rpareto).
- Plots used in EVT (evt_plot): Hill, DEdH, mean excess and qq against standard exponentials.
